# Website SOP - Verdant Oak Creative

## Goal
Build a 3-page StoryBrand-first website (Home, Pricing, About) that positions Verdant Oak as the guide for strategy-led creative growth.

## Inputs
- Brand: Verdant Oak Creative
- Purpose: connect business strategy to creative execution for measurable outcomes
- Aesthetic: Vapor Clinic adapted with grainy, green, builder-texture look

## Deterministic Rules
1. Customer is hero, brand is guide.
2. Home page contains: problem, guide, plan, stakes/success, proof, CTA.
3. Pricing page contains: clear tiers, fit guidance, risk reversal, FAQ, CTA.
4. About page contains: mission, guide authority, method, CTA.
5. Primary CTA options: Learn More / Book Strategy Call / Email.

## Edge Cases
- If testimonials are missing, use non-fabricated proof framing and request real proof later.
- If offer is unclear, package as staged roadmap + execution retainers.
- If aesthetic requests conflict, preserve readability and conversion clarity.
